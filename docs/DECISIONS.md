# QuakeCurrent 결정 기록

이 문서는 현재 유효한 제품·기술 판단과 재검토 조건을 요약합니다. 세부 구현은
[아키텍처](./ARCHITECTURE.md), 현재 범위는 [SSOT](./SSOT.md)를 기준으로 합니다.

상태는 다음 세 가지를 사용합니다.

- `채택`: 현재 구현과 검증의 기준
- `보류`: 조건이 갖춰질 때까지 구현하지 않음
- `대체`: 새 결정으로 교체됐으며 역사적 맥락만 유지

## 변경 규칙

중요한 결정을 바꿀 때 기존 행을 지우지 않습니다.

1. 기존 결정을 `대체`로 바꿉니다.
2. 새 ID로 대체 결정을 추가합니다.
3. 이유, 대안과 재검토 조건을 적습니다.
4. 같은 변경에서 SSOT·아키텍처·검증 가이드와 구현을 갱신합니다.
5. Review에서 이전 결정이 실제로 해결하지 못한 문제를 증거와 함께 기록합니다.

다음 변경은 결정 기록 대상입니다.

- framework, 데이터 저장소, 계약 방식과 workspace 경계
- 상태를 URL·client·server 중 어디가 소유하는지
- 성능·트래픽 기준과 승격 조건
- 배포·보안·관측성 정책
- 의도적으로 구현하지 않기로 한 비범위

단순한 파일명 변경, 내부 함수 분리와 동일한 계약을 유지하는 리팩터링은 별도 결정
ID 없이 관련 문서와 코드에서 설명할 수 있습니다.
